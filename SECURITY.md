# Security Policy

## Reporting a vulnerability

Please do not report security vulnerabilities in public issues. Use GitHub's private vulnerability reporting or create a private security advisory for this repository.

Include the affected version, a concise impact description, and reproduction steps that do not contain real prompts, credentials, or personal data. Do not attach user event queues or configuration files unless they have been sanitized.

## Supported versions

Security fixes are intended for the latest published version. Supported versions will be listed here after the first public release.
