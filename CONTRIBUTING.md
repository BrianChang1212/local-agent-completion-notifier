# Contributing

Contributions are welcome. Before opening a pull request:

1. Open an issue for significant behavior changes so the scope can be discussed.
2. Keep changes focused and avoid adding prompts, assistant responses, command lines, or environment variables to completion events.
3. Run the checks from the repository root:

   ```powershell
   npm ci
   npm test
   npm run package:verify
   ```

4. Describe the behavior changed, the checks performed, and any platform limitations.

By submitting a contribution, you agree that it may be distributed under the project's license. The project license must be selected before public contributions are accepted.
